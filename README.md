### 🛠️ Projects

**JP Mall — Commercial Management System**
*Full-stack academic group project*

A commercial proposal management system built for a shopping mall's commercial sector, designed to centralize proposal tracking and store/contract data. The project's design was grounded in a systematic literature review the team conducted beforehand on CRM and data centralization practices for shopping center management, then implemented as a REST API consumed by a web frontend.

**Highlights**
- REST API built with Go and Gin for managing commercial proposals, stores, and contracts
- PostgreSQL-backed relational data layer for proposals, stores, and contracts
- React + TypeScript frontend consuming the API
- Design grounded in a systematic literature review (SLR) on CRM and data centralization for shopping centers, conducted by the team before development began

**Built with:** Go · Gin · PostgreSQL · React · TypeScript · HTML5 · CSS3
